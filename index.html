🔥 設定 Firebase

首次使用需要設定 Firebase

1. 前往 Firebase Console → 建立專案
2. 「Build」→「Authentication」→ 啟用 Google 登入
3. 「Build」→「Firestore Database」→ 建立資料庫（測試模式）
4. 專案設定（齒輪）→「新增應用程式」→ Web → 複製設定貼到下方
5. 在 Firebase Console → 「Hosting」啟用，或使用 GitHub Pages 發布
